This course introduced the Model Context Protocol and how it enables
applications to connect to external tools and data sources without having to
build everything from scratch. It covered the three core building blocks of an
MCP server: tools that Claude controls, resources that the application controls,
and prompts that users trigger, as well as when to use each. It also covered
building an MCP client, discovering what tools a server offers, and testing
before connecting to a full application.
