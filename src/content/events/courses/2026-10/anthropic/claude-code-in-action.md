This course covered running Claude Code on longer, less supervised work and
trusting the result. It explored steering sessions with plan mode, directed
compaction and the rewind menu, and configuring Claude through a lean CLAUDE.md,
skills, permission modes and hooks that enforce the rules that cannot be
skipped. It also covered automating repeat work with scheduled routines,
headless mode and pull request review, and verifying unsupervised runs in
proportion to how little they were watched.
